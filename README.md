# Práctica de Laboratorio: RWD vs. AWD

Este repositorio contiene la implementación de un catálogo de hardware diseñado para medir y comparar el rendimiento de red y Core Web Vitals entre arquitecturas Responsive Web Design (RWD) y Adaptive Web Design (AWD).

**Tecnologías Utilizadas**
* Backend: Node.js, Express, EJS, express-useragent
* Frontend: HTML5, CSS3 (Flexbox)

**Instrucciones de Instalación**
1. Clona este repositorio en tu equipo local.
2. Abre una terminal en la carpeta raíz del proyecto.
3. Instala las dependencias necesarias ejecutando:
   `npm install`

**Instrucciones de Ejecución**
1. Inicia el servidor local con el comando:
   `node server.js`
2. Abre tu navegador web.

**Rutas de Evaluación**
* **Arquitectura RWD:** Ingresa a `http://localhost:3000/responsive`
* **Arquitectura AWD:** Ingresa a `http://localhost:3000/adaptive`
